# Aftermap 末日坐标 · 可玩版

Windows：解压整个压缩包，双击 `Aftermap.exe`。无需安装 Godot 或 Python。
Linux：解压后运行 `chmod +x Aftermap.x86_64`，再运行 `./Aftermap.x86_64`。

从源代码启动：安装 **Godot 4.6.2**，导入 `project.godot` 后按 F5 运行整个项目，或运行根目录 `run.bat` / `bash run.sh`。源代码在缺少内置字体时使用系统中文字体；Linux 可安装 `fonts-noto-cjk`。

## 目标

四人小队在南京的演示街区求生。建造短波电台，把联络提升到 100%，并度过第 7 天，即可获救；也可以挑战生存 30 天。所有幸存者阵亡则失败。

## 每日安排

每天有 2 次行动，出发探索、建造设施、联络救援各消耗 1 次。选择成员、调整夜间工作和基地治疗不消耗行动次数。

每名活着的幸存者每晚消耗 2 食物、3 饮水。工作与设施先产出，然后扣除口粮；缺粮缺水会损失健康。守卫与围墙可以减轻夜袭伤害。第一天建议先建净水器，再派侦察兵去便利店，之后逐步建立菜园。

## 外出操作

| 操作 | 按键 |
|---|---|
| 移动一步 | WASD / 方向键 / 点击视野内地面 |
| 搜刮相邻补给箱 | E |
| 切换潜行 | C |
| 近战 | 点击相邻感染者 |
| 切换射击模式 | F，然后点击视野内感染者 |
| 包扎治疗 | H，消耗 1 药品 |
| 原地等待 | Space |
| 撤离 | 回到左侧绿色撤离点旁，按 R |
| 玩法说明 | Esc |

玩家行动一次，感染者也行动一次。射击消耗弹药并发出很大的噪声。80 回合后会被迫撤离，损失一半补给并受到伤害。阵亡会永久失去该成员和本次携带的补给。

黄色补给箱被搜刮后颜色变暗。带回基地前，物资保存在本次行动的背包里。深色地块代表已探索但当前不可见；完全未知的地块不能直接移动。

## 存档

有效行动后自动保存，菜单“继续战役”恢复到离开时的阶段，包括战斗中途和未选择的夜间事件。存档保存在 Godot 的用户数据目录，Windows 通常为 `%APPDATA%/Godot/app_userdata/Aftermap/`。请保留 `.dat`、`.meta` 与相应 `.bak` 文件；主档损坏时会尝试备用档。新战役需要确认后才覆盖旧进度。

## 范围

这是保留原 Godot 工程、内容数据库和战斗基础模块的一版单机可玩游戏。包含六种地点、四名初始幸存者、四种可建造设施、六个夜间事件及三种战役结局。地图来自项目的南京演示设定，并非联网获取的真实城市导航。原项目的完整迁徙、关系剧情与更多设施仍属于后续扩展方向。

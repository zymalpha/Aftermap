# ADR-0007：接通可玩的单机战役

- 状态：已实现，待维护者合入
- 日期：2026-09-09
- 关联：ADR-0001、0003、0004

## 问题

原工程已有内容数据库、命令队列、战斗算法和多个界面，但玩家无法从主菜单完成探索、带回物资、夜间结算与结局。仅验证独立模块不能证明游戏可以游玩。

## 决策

保留 Godot 4.6.2、Compatibility 渲染器及原领域模块。新增 `CampaignActions`，由 `GameSession.issue_command` 统一执行；界面只发命令。战役阶段为基地、战术、事件、报告与结局，状态完整保存在 `base_state.campaign`。战斗继续使用原有视野、寻路和命中计算。

`content/campaign/scenario.json` 集中描述这一版的地点、建造成本和夜间选择，使用专门的 JSON Schema 参与既有校验器。局部标识如 `water`、`grocery` 仅作为战役配置键，不冒充原内容数据库的全局 ID；地点通过 `poi` 字段关联演示地图设定。中文文案集中在场景、`CampaignText` 与配置文件，领域动作返回消息键。

菜单通过真实 SceneTree 生命周期切换，不手动重复调用 `_ready`。每次有效玩家命令后自动保存，继续游戏重载内容数据库。JSON 会把数字读成浮点数，因此战役整数状态在恢复时统一还原；64 位 RNG 状态改为十进制字符串存储，读取时兼容原数字形式。旧存档已丢失的随机数精度无法逆向恢复；缺少战役字段的旧档会初始化新战役字段。

## 验证与交付

默认回归运行实际 Godot 引擎、既有领域测试、新战役测试和地图管线 pytest；千种子和性能压力测试保留 `--full` 入口。过时的 Director 占位断言更新为真实内容选择契约。脚本错误和非零返回码使构建失败。

另外通过真实场景与键盘事件验证开始、搜刮、移动、途中存档续玩、撤离、入夜和建造，并在 Xvfb 中保存原生渲染截图。Actions 校验官方引擎与模板的 SHA256，导出 Windows、Linux，执行 Linux 导出程序的启动测试。发布包包含中文字体子集、字体许可及操作说明。

## 范围与后果

当前交付是六地点、四角色、四设施、六夜间事件、三结局的离线单机游戏。原工程更多事件链、迁徙和关系模块仍保留，尚未全部接入此战役。没有联网城市抓取或服务端依赖。Windows 导出由 Linux CI 完成，Windows 实机运行仍需后续人工验收。
